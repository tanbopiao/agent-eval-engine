# 回归用例沉淀（tests/）

本目录是评测引擎的回归测试载体。每次改动（判分逻辑、台账结构、分离纪律、
MCP 壳工具面）之后，回归测试必须全绿方可提交：

```bash
python3 -m unittest discover -s tests -t .    # 仓库根目录下运行
```

## 回归范围与历史

| 日期 | 触发改动 | 回归结论 |
| --- | --- | --- |
| 2026-11-28 | 首次建立独立测试目录（自 tests/ 内嵌 selftest 沉淀而来），覆盖封印/确定性判分/分离纪律/语义挂起/台账防篡改五域 | 23 例全绿 |

## 回归铁律

1. **篡改现形回归**：`test_篡改现形` 永不删除——台账验链是本引擎的存在理由；
2. **分离纪律回归**：同源拒判、未登记拒判两例永不放宽——判分可复算性优先；
3. **不虚报回归**：PENDING_SEMANTIC 与 UNCERTAIN 两例锁定「不猜分」行为；
4. 新增行为先加回归用例再改实现（红→绿）。
